Cada envío en su caja.

Juez Miau es un juez automático para concursos de programación. Califica rápido y parejo: cada solución corre sola, sin red, con su propio núcleo y los mismos límites para todos. Tú organizas el concurso; el gatito revisa las cajas.

Las mismas reglas para todas las cajas.

Cada envío corre dentro de un contenedor Docker aislado. Nada que haga un equipo le quita tiempo, memoria o ventaja a otro.

  • Sin red
  • 1 núcleo por caso
  • Límite de tiempo
  • Límite de memoria

El contenedor no tiene salida a internet ni a la red del laboratorio. Cada caso de prueba tiene un núcleo de CPU reservado, así que ninguna corrida le roba tiempo a otra. Los límites de tiempo y de memoria son los mismos para todos los envíos del problema; si un envío se pasa, el veredicto es TLE o MLE.

Cómo se ordena el marcador

Gana quien resuelve más problemas. El empate se rompe con la penalización: el minuto de cada aceptado más 20 por cada rechazo previo. Un error de compilación no cuenta.

Un reloj para todo el concurso

El mismo tiempo en el panel, en la app y en el proyector. El staff lo inicia, lo pausa y lo termina.

El final se sella

En la última parte el marcador público se congela. Los envíos se siguen juzgando y el resultado se revela en la premiación.

El gatito revisa cada computadora.

La app de escritorio le manda al juez un latido periódico con los procesos abiertos, los monitores conectados y las memorias USB de cada equipo. Cada edición define qué está prohibido.

Si algo rompe una regla, el staff ve la alerta y puede suspender al equipo. El equipo nunca ve la alerta.

Instrucciones de armado.

Todo corre en un solo servidor del laboratorio con Docker Compose. Se monta unos días antes del concurso y se desmonta después.

  1. Consigue una máquina

    Palomea lo que ya tienes:

  2. Clona y configura

    $ git clone https://github.com/LaBoa99/juez-miau
$ cd mi-concurso-monorepo/deploy
$ cp .env.example .env

    En .env pon la dirección pública, las contraseñas y los secretos.

  3. Levántalo

    $ docker compose up -d --build
web      Up   api    Up
worker   Up   redis  Up
postgres Up

  4. Entra al panel

    Abre la dirección pública con el usuario administrador del .env y crea tu primera edición. Reparte la app de escritorio en las máquinas de los equipos.

¿Tu laboratorio no tiene internet? Prepara las imágenes en otra máquina y cópialas; la guía explica cómo.

Lo que viene en el compose.

Un solo archivo, deploy/docker-compose.yml, levanta todo el concurso. Es el mismo para el día del concurso y para desarrollo.

  • webCaddy

    Sirve el panel de staff y pasa /api y /socket.io a la API.

    :80 · :443
  • apiNestJS

    La API del panel y de la app de escritorio. Al arrancar carga los datos iniciales.

    interno
  • workerEl juez

    Mismo código que la API. Toma los envíos de la cola y los corre en contenedores.

    sin puertos
  • postgresPostgreSQL 14

    Ediciones, equipos, problemas, envíos y bitácora.

    solo 127.0.0.1
  • redisRedis 7

    La cola de envíos que reparte el trabajo al juez.

    solo 127.0.0.1
  • judge-*Lenguajes

    Imágenes de gcc, Java, .NET, Node y Python. Solo se descargan; terminan en Exited (0).

    sin puertos
